# 藏寶圖三條航線（赫拉／主航線／宙斯）與 UI 美化

日期：2026-08-05
狀態：已實作

## 背景

原本的地圖面板只有一條中央航道，兩座 JP 小島擠在分歧站上方同一列、左右貼著面板邊。企劃希望「看起來就是三條路線：赫拉／主航線／宙斯」，並把面板拉寬、順手美化。

## 版面

| 項目 | 舊 | 新 |
|---|---|---|
| 盤面 `grid.x` | 265 | 195（格子仍為 130×5 欄，WAYS 跟著左移到 127） |
| 地圖 `mapPanel` | x 925 / w 300 | x 865 / w 390（右側留 25px，與盤面間隔 20px） |

面板內分三條航道，**兩側用固定像素寬（`MAP_LANE_W = 110`），中央吃剩下的寬度**（`mapMainLaneW()`）。這樣在調校面板拖寬面板時，變寬的只有中央航道，兩側維持一致的寬度。

- 左航道中心 = `MAP_PX + 55`（赫拉）
- 中央航道中心 = `MAP_PX + MAP_PW / 2`（主航線，四站地標都在這裡）
- 右航道中心 = `MAP_PX + MAP_PW - 55`（宙斯）

`mapColX(side)` 是這三個中心的單一事實來源；小島半寬（`mapIslandHW()`）、羅盤間距（`beaconGap()`）、名牌寬度上限、支線兩端（`sideRouteEnds()`）全部由它推算。

## 三條航線的視覺

| 元件 | 說明 |
|---|---|
| `drawMapLaneBands` | 每條航道一層很淡的垂直漸層（左＝赫拉粉、中＝金、右＝宙斯黃）＋航道間虛線分隔 |
| `drawMapLaneTabs` | 標題橫幅下方三個小名牌「👑 赫拉航線／⚓ 主航線／⚡ 宙斯航線」。**畫在雲霧之上**，所以開局全霧時就看得出有三條路線（航線名稱不算劇透，小島本體仍被霧蓋住） |
| `drawMapSideRoutes` | 支線棧道：從第 1 站（分歧島）的側緣斜上接到該側小島的內側緣 |
| `drawMapDock` | 出發港的小碼頭 |

狀態呈現：分歧未定案時兩側名牌與支線都壓暗（alpha 0.42）；定案後本局那條轉金亮起、名牌上該尊神的色與光暈，落選那條壓到 0.16。

**三條路線在第 1 站分家**，不是在出發港：主航線繼續往上一站，兩條支線各自通到自己的 JP 小島。出發港到第 1 站只有一條主航道。

## 小島上的節點：燈塔 → 羅盤

`drawIslandCompass()` 取代 `drawBeacon()`：

- 未點亮＝深色盤面、指針歪著慢慢晃
- 點亮＝黃銅盤面（不管島身什麼顏色都讀得出來）、指針指正北並呼吸，外圈光暈走該尊神的色
- `anim > 0` 播點亮瞬間的擴散環

盤面半徑跟著 `beaconGap()` 縮放，`JP_NODES` 調到 6 也不會互疊。

## 支線載具：潛水艇 → 小船

`drawMapBoat()` 取代 `drawMapSub()`：船身 18px（約主航道那艘 ⛵ 的一半）、三角帆是本局神的主題色、移動中有尾流白弧、待命時隨浪微浮。

小船沿著支線走同一條線與同一個弧度（`sideRoutePoint()`），停靠點是支線上的比例 0.42（待命）→ 0.90（島邊）。

**變數名與調校鍵沒有跟著改名**（`mapSub`、`beaconAnim`、`TIMING.mapSub`、`TIMING.mapBeacon`），避免舊的匯出設定失效；調校面板顯示的中文已改為「支線小船航行」「羅盤點亮」。

## 其他

- `TUNE_VERSION` 3 → 4：預設版面改了，舊 localStorage 必須作廢，否則會被舊座標蓋掉。
- `drawMapChain` 加了選擇性參數 `{alpha, bow}`：支線才有辦法自訂明暗與弧度（`bow: 0` 可打直）。
- v1 規則不畫航道／小島／支線／碼頭；地標方塊改成吃滿加寬後的面板（`rw` 依 `MAP_PW` 算），否則加寬後會顯得空。
- 羅盤玫瑰裝飾在 v2 縮小並淡化，避免壓到右側航道。
