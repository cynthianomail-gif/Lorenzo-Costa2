## 與舊 v2 的差異

| | 舊 v2 | 新 v2 |
|---|---|---|
| 分歧位置 | 第 3 關 | **第 1 關** |
| 前兩關 | 藍／綠 隨機先後 | 取消 |
| 關卡數 | 5（含第 5 關進階合成） | **4** |
| 兩條航線的獎勵 | 宙斯給倍數／赫拉給結算彩金 | **兩尊神倍數相同**，神只決定能拿哪座 JP |
| JP 取得 | 第 5 關進階合成 1 次 | **小島節點制**，每次雙色進階合成點亮 1 個 |
| 地圖形狀 | 分歧後左右兩欄各走到頂 | **單欄主航道**，分歧兩側各掛一座 JP 小島 |

## 關卡

| 關 | 條件 | 完成獎勵 |
|---|---|---|
| 1 | 紅｜金 同時開放競速，先完成合成之顏色定本局的神 | 盤面 ×2，開啟對應 JP 小島 |
| 2 | 剩餘三色隨機一色，合成 1 次 | 盤面 ×3 |
| 3 | 剩餘兩色隨機一色，合成 1 次 | 盤面 ×5 |
| 4 | 最後剩餘一色，合成 1 次 | 盤面 ×10 |
| JP | 開島後每次雙色進階合成點亮 1 個節點 | 節點點滿 → 該神 JP 彩金 |

- 盤面倍數預設 ×1，本局所有連爆得分與當前倍數相乘。
- 紅先 → 右側宙斯小島；金先 → 左側赫拉小島。
- 「剩餘三色」＝ 紅／金落敗的那色 ＋ 藍 ＋ 綠，於分歧定案時洗牌填入第 2~4 關（`fillRemainingSteps()`）。
- JP 彩金獨立，不與盤面倍數相乘。節點數量正式版由 SERVER 給，demo 預設 2、調校面板可調 1~6。

## 三條排除規則

都靠同一套「合成事件流水號」處理，`requestQuestAdvance()` 每筆入列時記下 `seq` 與 `atProgress`。

**1. 條件揭露前完成的合成不算**
`atProgress` = 合成當下已揭露到第幾關。佇列處理時 `atProgress !== questProgress` 就丟棄，因此一次事件最多只推進一關 —— 玩家必須先看到條件，再合成。

**2. 開島前完成的雙色進階合成不計入節點**
分歧定案時記下 `jpIslandSeq`；只有 `seq > jpIslandSeq` 的進階合成才點亮節點。用 `>` 而非 `>=`，所以「同一次 1×4 既定分歧又是進階合成」不計入。

**3. 同一次連爆中金紅同時達成**
以先觸發者為準。單色合成由 `findBaseSynthCandidates()` 以 row 外層、col 內層掃描（即上至下、左至右的閱讀順序）產生，先入列者先處理；一次 1×4 同時湊齊兩色時，`tieBreak` 取較左的合成格顏色。

## 地圖版面

地圖標題兩個版本統一為「📜 亞格號任務」（v2 頂端已不是聖林／神殿，×10 就是終點）。

面板 300×462，v2 為單欄四站，分歧上方多一列放兩座小島：

```
        ×10        ← 第4關   y=220
        ×5         ← 第3關   y=288
        ×3         ← 第2關   y=356
 赫拉 ─────── 宙斯   ← 小島列  y=424（主航道從中間穿過）
        分歧       ← 第1關   y=492
        起點                y=544
```

`MAP_STEP_YS` 依 `RULE_VERSION` 給不同陣列，`syncLayoutDerived()` 重算；切換規則版本時要一併呼叫，否則節點座標會停在舊版本。

- 第 1 關在分歧未定時畫成**左金右紅的雙色塊**（`nodeColor2()` / `drawMapBlock` 的 `color2`），名牌寫「×2 金 vs 紅 競速」；定案後收成單色並套用該色美術。
- 小島在分歧定案前**整組不畫**（船還在起點時不該先看到兩尊神）；定案開島後才出現，畫在霧之上，本局的神那座亮起、另一座壓到 26% 透明度。
- 船全程走中間主航道，不再因分歧轉向（`stepShipX()` 恆回中線）。

## 驗證

以真的函式跑過八個情境，全過：

| 情境 | 結果 |
|---|---|
| 紅先合成 → 宙斯，四關走完 | route=0、倍數 ×2→×10、剩餘三色不重複且不含紅 |
| 金先合成 → 赫拉 | route=1 |
| 同一次事件金紅都達成，tieBreak=金 | route=1 |
| 第 1 關未過就先合成藍 | 該筆作廢，progress 停在 1 |
| 開島前的進階合成 | 節點 0 |
| 開島後連做三次（節點數 2） | 1 → 2 → 2（不超過） |
| 同一次 1×4 既定分歧又是進階合成 | 開島成功但節點 0 |
| 節點數改 3 | 三次後點滿 |

實機以 v2 轉了數十局，console 無錯誤；地圖在「分歧未定」與「分歧定案＋點亮 1 節點」兩個狀態都截圖確認過。
