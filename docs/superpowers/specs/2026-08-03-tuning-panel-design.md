# 亞格號 調校面板設計文件（節奏 + 佈局 + 取圖）

- 日期：2026-08-03
- 依據：`亞格號_260730_新增美術說明.xlsx`「視覺流程圖」＋「美術需求說明」編號 18／19／20／21
- 參考實作：海克力士 demo `docs/superpowers/specs/2026-07-06-tuning-panel-design.md`
- 目標檔案：`index.html`（單檔 Canvas 遊戲，1280×720，60fps）

## 目的

讓企劃在遊戲執行中即時調整三類參數，不需改程式碼：

1. **節奏**：各段演出時長，預設值對齊企劃書秒數。
2. **佈局**：畫面物件的位置與尺寸，直接在畫布上拖曳。
3. **取圖**：圖示被分裂演繹橫切成細條時，要取原圖的哪一部分。

調整即時保存於瀏覽器，並可匯出 JSON 交回工程端寫成正式預設值。

## 整體架構

- 畫面左上新增 **🔧 按鈕**（沿用現有 📊 按鈕樣式），開啟浮動面板，頂部把手可拖曳移動。
- 面板分三分頁：**⏱️ 節奏 / 📐 佈局 / ✂️ 取圖**。
- 三份集中設定物件作為單一事實來源：
  - `TIMING`：演出時長，**單位秒**，內部以 `TF(秒) = Math.max(1, Math.round(秒 × 60))` 換算幀。
  - `LAYOUT`：可移動物件的座標／尺寸（px），預設值 = 目前程式寫死的座標。
  - `CROP`：8 個一般圖示各一組取圖設定。
- 程式中散落的幀數常數（`SYNTH_FLASH_FRAMES`、`popWaitTimer = 90`、`MAP_MASK_FRAMES` 等）改為引用 `TIMING`；繪製座標（`MAP_PX`、`BAR_Y`、`GRID_X/Y` 等）改為引用 `LAYOUT`；`drawSymbolSplit` 的切圖改為引用 `CROP`。

## 節奏分頁

沿用海克力士的甘特圖：每個分組是一條獨立時間軸（t=0 為該階段開始），拖色條改起點、拖右緣改時長；右側兩欄數字框為起點／時長。px 與 0~1 強度類參數走一般數值滑桿。範圍預設 0～5 秒、步進 0.05 秒。

`AUTO_SPIN_DELAY` 在程式中被引用兩次卻從未宣告，按下 AUTO SPIN 會丟 ReferenceError。改由 `TF(TIMING.autoSpinDelay)` 提供後修復。

- **Turbo 節奏**：企劃書「Turbo 全盤齊停」，但 demo 未實作 Turbo 模式。

## 取圖分頁

### 問題

分裂演繹把一格橫切成 2／3／4 條，每條都用同一張方形原圖以 `drawCover` 繪製 —— cover 會等比放大後置中裁切，結果每條都只看得到角色胸口那一段。企劃需要指定取原圖的哪個位置（例如往上取頭部）。

### 設定

8 個一般圖示（id 0–7）各一組，×2／×3／×4 三種分裂數共用：

| 欄位 | 範圍 | 說明 |
|---|---|---|
| `mode` | `cover` / `contain` / `stretch` | 裁切（現行）／完整縮進條帶留邊／拉伸填滿 |
| `fx` | 0~1 | 焦點 X，0=靠左、0.5=置中、1=靠右 |
| `fy` | 0~1 | 焦點 Y，0=取頂端、0.5=置中、1=取底部 |
| `zoom` | 0.5~3 | 縮放，>1 放大（取更小範圍）、<1 縮小 |

初版預設 `{ mode: 'cover', fx: 0.5, fy: 0.5, zoom: 1 }`，等同舊行為。
2026-08-03 企劃實調後匯回的正式預設值（全部 `cover`、`fx` 0.5、`zoom` 1，只調 `fy`）：

| id | 圖示 | `fy` | id | 圖示 | `fy` |
|---|---|---|---|---|---|
| 0 | 海克力斯 | 0.50 | 4 | 美狄亞 | 0.23 |
| 1 | 木棒 | 0.45 | 5 | 魔法 | 0.52 |
| 2 | 伊阿宋 | 0.38 | 6 | 奧菲斯 | 0.33 |
| 3 | 刀盾 | 0.45 | 7 | 七弦琴 | 0.21 |

### 繪製規則

`drawFocus(ctx, img, x, y, w, h, crop)` 取代分裂條帶的 `drawCover`：

- `cover`：`s = max(w/iw, h/ih) × zoom`，來源取樣矩形寬高 = `w/s, h/s`，左上角 = `(iw - sw) × fx, (ih - sh) × fy`，並鉗制在圖片範圍內。
- `contain`：`s = min(w/iw, h/ih) × zoom`，整張畫進條帶置中，多餘留白透明。
- `stretch`：整張圖直接拉伸填滿條帶，`fx/fy` 無作用、`zoom` 無作用。

### 預覽

分頁最上方放一塊 `<canvas>` 即時預覽：選中的圖示同時畫出 1×1、÷2、÷3、÷4 四種呈現，拖滑桿即時更新，不必等 spin。

## 保存與匯出

- 任何調整即時寫入 `localStorage`（鍵：`argo_tuning`）。
- 格式：`{ version: 2, timing: {...}, timeline: {...}, layout: {...}, crop: {...} }`。
- **套用並試轉**：提交輸入框、存檔，若在 IDLE 就直接 spin 一次。
- **重設為預設**：只重設當前分頁。
- **匯出全部設定**：完整 JSON 複製到剪貼簿，交回工程端寫成正式預設值。

## 邊界處理

- localStorage 解析失敗或版本不符 → 移除、退回預設，不阻擋遊戲。
- 數值超界鉗制到範圍內；未知鍵忽略、缺漏鍵補預設。
- `TF()` 下限 1 幀，避免時長調到 0 造成除以零或卡死。
- 佈局拖曳不設邊界（允許拖出畫面），可用「重設為預設」救回。

## 測試

以瀏覽器開啟 `index.html` 手動驗證：

- 節奏：調「合成演繹」「首格落定」後 spin，確認演出時長改變；重設後回到企劃書值。
- 佈局：拖曳盤面與藏寶圖面板，確認繪製與點擊判定同步移動；重新整理後保留。
- 取圖：把伊阿宋 `fy` 調到 0，確認分裂條帶改取頭部；切 `contain`／`stretch` 確認三種模式都正確。
- 邊界：手動塞壞 localStorage，確認自動退回預設。
